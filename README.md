
# Continous Integration

1. Uruchomienie Workflow: Pull request na main, push na main i przycisk
2. Lista Kontroli:
- Set up jpb
- Confirm Runner
- Checkout Repository
- Show Directory
- Setup .NET
- Check repository structure
- Restore Dependencies
- Build Project
- Publish Project
- Upload build artifact
- Run Project
- Post Setup .NET
- Post Checkout repository
- Complete Job
3. Artefakty mozna pobrac z runnowanych buildow. Logi znajduja sie w zakladce actions, build.
4. DOTNET_VERSION: 10.0.x PROJECT NAME: Warp07.demo.csproj
5. Zadania wykonane na WARP. Artefakt przechowywany jest przez 7 dni.
